# ovidiu.dev

The source for [ovidiu.dev](https://ovidiu.dev), the personal website and engineering blog of [Ovidiu Bute](https://www.linkedin.com/in/ovidiubute/).

I write **Engineering for the Agentic Era**: practitioner notes about how AI changes software architecture, infrastructure, tool selection, and the way engineering teams make decisions. The site also collects selected work and context from my career building and leading production software systems.

## Topics

- Engineering leadership and software architecture
- AI-native and agentic software
- Multi-tenant SaaS and authorization
- Metadata, ingestion, search, and developer platforms
- Infrastructure as code and production engineering
- TypeScript, monorepos, testing, and maintainable systems

## Technology

The site is built with [Gatsby](https://www.gatsbyjs.com/) and React, styled with SCSS, and deployed through AWS Amplify.

It extends [gatsby-theme-developer](https://github.com/miguelbemartin/gatsby-theme-developer), originally created by Miguel Ángel Martín, with custom pages, components, styles, metadata, and long-form content.

## Run locally

The project requires Node.js 22 or later and npm 10 or later.

```bash
npm install
npm run develop
```

The development site is available at `http://localhost:8000`.

Create a production build with:

```bash
npm run build
```
